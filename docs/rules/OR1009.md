# OR1009 — Redundant 'ToList()' / 'ToArray()'

**Status: new (alpha).** Default severity `hint`. Quick fixes run through Refyntra's edit actions.

Reports a copy whose only purpose is to be enumerated once:

- `x.ToList().Any()` / `.ToArray().Sum()` … — the next LINQ operator runs immediately and enumerates once anyway.
- `foreach (var i in items.ToList())` (also after `Where`/`Select`/`OrderBy`… with simple lambdas) when `items` is an
  in-memory collection local or parameter that the loop does not touch.

```csharp
xs.ToList().Any()                         // OR1009 → xs.Any()
foreach (var i in items.ToList()) …       // OR1009 → foreach (var i in items) …
```

**Quick fix *Remove the redundant copy***.

### Not reported

- A copy before a deferred operator (`ToList().Where(…)`: the copy fixes the moment of evaluation), a kept copy
  (`var copy = xs.ToList()`), a copy whose `List<T>` member is used (`ToList().Contains(3)` binds to List.Contains).
- `foreach` over a copy when the loop mentions the source, adds/removes/clears/sorts any collection (`alias.Add(i)` may
  be the same list), assigns an indexer, awaits or yields; when the source is lazy (`IEnumerable<T>`: the copy
  separates producing from consuming) or a field; when a lambda of the chain calls or assigns anything.
- `IQueryable` sources (`ToList()` there runs the query).

Fixture: `Cases/Linq.cs` (4 reported, 8 guards).

## Settings and suppression

- Setting `refyntra.rules.OR1009`: `off | hint | info | warning | error` (default `hint`). `hint` shows dots under
  the code and no Problems entry.
- Reported for the C# files open in the editor (the client sends their URIs with `analysis/run`, protocol 1.16); each
  document is analysed on its own and its result is reused until its text or a signature of its project changes.
- Suppress like a compiler warning: `#pragma warning disable OR1009` … `#pragma warning restore OR1009` (a bare
  `#pragma warning disable` too), or `[SuppressMessage("<category>", "OR1009…")]` on the member, type or assembly
  (`Target = "~M:…"` / `Scope = "namespaceanddescendants"` are honoured). Generated code is never analysed.
- Quick fixes are Refyntra edit actions: computed by the host, applied only when the document has no new compiler error,
  one undo step. *… in document, project or solution* applies the same fix at every result of the scope as one
  previewed plan (Fix in scope, `csharp.fixAll`); results whose fix would add a compiler error are skipped and counted.
