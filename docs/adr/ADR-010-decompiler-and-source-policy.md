# ADR-010: Decompiled sources and the source policy for metadata

Status: Accepted (alpha)

## Context

Refyntra's navigation (Navigate To, Related, Find, Usages, File Structure's inherited members, stack traces, Smart
Step Into) ends at symbols without source in the solution: `string`, `IMediator`, `Exception.StackTrace`. Rider and
Visual Studio show such symbols as read-only decompiled C# ("go to metadata"), or as the original file when the
library ships it. Refyntra deliberately registers no Definition provider (the delegated languages and VS Code keep
F12; see the integration test "does not register Definition/Rename providers"), so metadata must reach the user
through Refyntra's own entry points.

Constraints:

- Local processing only (docs/guide.md, "Privacy and local processing"): no network access by default, and nothing a user
  has not asked for leaves the machine.
- One bundled host, licences compatible with MIT and listed in THIRD_PARTY_NOTICES.md (ADR-005).
- No files written into the workspace or next to the assemblies; nothing locked that a build may want to overwrite.

## Decision

1. **Decompiler: ICSharpCode.Decompiler (ILSpy's engine), MIT, NuGet, pinned** (`Directory.Packages.props`,
   11.1.0.9782), referenced by `Refyntra.Semantics` and bundled in the host. It needs only System.Collections.Immutable
   and System.Reflection.Metadata, which .NET 10 already provides. Its notices are generated by `pnpm notices`.
2. **Protocol 1.17 `code/metadataSource`.** The host resolves a symbol (symbol id, documentation id + assembly, a
   position in a solution document, or a position in a metadata document), finds the top-level type, and returns
   one document per type: `refyntra-metadata:/<assembly>/<Namespace.Type>.cs`, the full text (header, usings,
   namespace, the type with all members and XML documentation), every declaration with its documentation id and
   ranges, and assembly facts (name, version, referenced path, implementation path, MVID, origin). The client keeps
   no symbol tables: navigation inside a document asks the host again with the document's type and the position.
3. **Which file is read.** The metadata reference of the project. A reference assembly (`ReferenceAssemblyAttribute`)
   is mapped to its implementation on the same machine: `dotnet/packs/<Framework>.Ref/<v>/ref/<tfm>` →
   `dotnet/shared/<Framework>/<v'>` (same major; the exact version first), NuGet `ref/<tfm>` → `lib/<tfm>`; type
   forwarders are followed (`System.Runtime` → `System.Private.CoreLib`). XML documentation comes from the `.xml`
   next to the referenced file (the targeting pack's documentation). When no implementation exists locally the
   reference assembly itself is decompiled and the header says that members have no bodies.
4. **Source policy (setting `refyntra.metadata.sourceLink`).**
   - `embeddedOnly` (default): if the assembly's portable PDB — embedded in the DLL, or a `.pdb` next to it whose id
     matches the CodeView entry — contains the source file of the type (embedded source, `EmbedAllSources` /
     `EmbedUntrackedSources`), that file is shown. The document of a partial type is the one with the requested
     member, else the one with most method bodies; types without bodies use the compiler's type-to-document table.
   - `off`: always decompile.
   - There is no download option. Source Link JSON is never read for URLs, symbol servers are never asked, and the
     build-machine path in the CodeView entry is never opened. Decompilation resolves references only from the
     project's own reference paths and the implementation directory (no GAC probing, no search of other folders).
5. **Caching and cancellation.** One decompiler (type system) per assembly MVID, at most eight, least recently used
   evicted; documents per (MVID, type, policy), at most 128. A rebuilt assembly has a new MVID and is decompiled
   again; an unchanged deterministic build hits the cache. Images are read into memory (no file stays open or
   locked). Requests are cancellable; a cancelled build caches nothing.
6. **Mapping back into the solution.** The document's text is compiled with Roslyn against the project's references
   (a throw-away compilation; the decompiled type shadows the referenced one). A declaration or reference at a
   position becomes a documentation id and is resolved in the project's compilation — so it has a normal symbol id:
   Find Usages from a metadata document lists usages in the solution, and a type that has source in the solution
   opens its file. Locals and parameters stay in the document.
7. **VS Code side.** A read-only `TextDocumentContentProvider` for the scheme (C# grammar for highlighting), a hover
   for this scheme only, `Refyntra: Go to Metadata / Decompiled Source` (palette, status bar menu, context menu of
   metadata documents) and, in metadata documents only, F12 (go on) and Shift+F12 (Find Usages) under the Refyntra
   key presets. The entry points that previously stopped at metadata open the document instead: Navigate To
   ("Decompiled declaration"), Related and Find (library symbols), File Structure (inherited library members), the
   stack trace view (frames of framework / library code without solution source) and Smart Step Into (the refusal
   offers "Open Decompiled Source"). A restored editor after a window reload asks the host again from the URI.

## Consequences

- The VSIX grows by the decompiler assembly: 3.1 MB uncompressed, about 1.5 MB compressed in the package.
- XML documentation appears only where the `.xml` file exists next to the referenced assembly (some environments,
  such as the .NET SDK container images, restore NuGet packages without their XML files).
- Decompiled text is ILSpy's rendering: names of locals, some syntax (async state machines, pattern matching,
  `foreach` on spans) may differ from the original; Rider's own decompiler differs in the same places.
- Implementation-only types referenced from decompiled BCL code (internal helpers of `System.Private.CoreLib`) are
  not in the project's reference assemblies, so go to definition on them answers "no symbol".
- Sources outside the PDB (Source Link to GitHub, symbol servers) are not shown. A future opt-in download policy
  would need its own setting, trust check and ADR amendment.
- Large types (System.String: about 5,000 lines) take a few hundred milliseconds the first time; later requests
  for the same assembly reuse the type system.
